# 搭子小馆：每日金币与消费会员

已上线：https://malatang.oneplums.cn/ 。版本 `20261103T112758Z`，可回退版本 `20261103T105249Z`。

## 当前规则

- 每天首次打开自动赠送100金币，同一浏览器同一天只发一次。余额可以累积，未到店的日期不补发。页面保持打开时也会检查跨日；等级不改变每日赠额。
- 不需要闯关、不用达到分数。取消旧的见面礼80、游戏结算奖励、每日首过20和强制早餐三单。烧烤/火锅/早餐没有倒计时结束或超时失败；火候会自然变化，可暂停，点评只作娱乐参考。
- 烧烤选串后按标价确认下单；奶茶按配方确认下单；火锅免费开锅、每份食材下锅前确认价格；早餐每份10金币，含可选鸡蛋和最多三种配菜，可自由续点。
- 麻辣烫免费夹菜、称重、查看20位角色点评；底栏预告金币价，点击“确认开吃”再扣币。金币价按模拟金额向上取整。相同账单再次打开不重复扣款，重新夹一盆可再次用餐。
- 下单扣币，实际消费1金币增加1会员成长。装扮购买也计入消费；切换已购装扮不重复收费。
- 未完成用餐离开小店会退回本餐扣币并撤回成长。刷新导致的未完成订单会显示找回退款入口。多标签页取消订单后，原页面同步回到选餐状态。吃完的订单不能再退款。

首页与装扮铺显示余额、消费成长、下一级差额和等级门槛；会员获得称号、门口标记及会员卡配色。所有菜品自由选择，不按等级锁定。

## 旧数据与范围

旧钱包余额、已购装扮、当前装扮及收支账本保留。会员成长从新版启用后的实际消费开始计算，不追溯旧版本的消费；升级当天仍可领取新版100金币。

这是当前浏览器的模拟金币账本，无真实支付、充值、账户或跨设备同步。清除网站数据会清空记录；存储被禁用时页面明确提示仅保留本次会话。保留原有120种食材与手绘SVG画风。

## 修改位置
