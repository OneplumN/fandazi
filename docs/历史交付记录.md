# 麻辣搭子 · REA 逆向交付

目标：https://malatang-lovat.vercel.app/ 。采集日期：2026-11-03。

本项目是从线上发布物恢复的可运行前端，包含可编辑的格式化业务 JavaScript、原站 CSS、22 张角色 WebP、原始发布包和 REA 证据。不是原作者的 Git 仓库；原始 TypeScript/JSX、注释、组件文件名和后端源码没有恢复。

当前线上主域名为 https://fandazi.oneplums.cn/ 。旧站保留存档迁移入口；开吃动作已增加夹起、送入口与咀嚼反馈，详见 `docs/开吃动作精修.md`。新首页已加入“今天吃什么”、三位搭子与吃完小票，详见 `docs/推荐搭子小票与新域名.md`。最新采用“每日100金币 + 用餐消费 + 累计消费会员”，取代历史闯关奖励，详见 `docs/每日金币与消费会员.md`。

## 启动

需要 Node.js 18 或以上，无需安装依赖：

```sh
cd /Volumes/oneplums/workspace/小项目/malatang-reversed
npm start
```

打开 http://127.0.0.1:4173/ 。可用 `PORT=4174 npm start` 改端口。直接双击 HTML 不支持 ES modules，请使用本地服务。

## 修改位置

- `src/app.js`：从发布包中分离的业务代码，保留压缩后的符号名；已经格式化，包含数据、SVG 食材、选菜状态、价格计算、推荐、评价和管理页面。
- `vendor/react-runtime.js`：原包中的 React 运行库；应用通过 ES module 导入原有别名，不依赖 CDN。
- `public/assets/index-DsnbFhCh.css`：原站样式。
- `public/art/char/`：22 张角色图。
- `docs/ingredients.json`：120 种食材的数据导出，供查阅；实际运行数据仍在 `src/app.js` 的 `Bm/qm` 中。
- `docs/code-map.md`：业务函数及对应行号。
- `docs/逆向分析.md`：功能、规则、接口和证据边界。
- `snapshots/`：未修改的 HTML/JS/CSS 发布物。
- `evidence/`：REA 6.7.0 静态与浏览器执行证据、场景输入、下载来源及 SHA-256。

## 已验证与范围

REA 实际执行原站与本地的“加载 → 夹菠菜 → 上秤”。菠菜 35g，按 19.8 元/斤计算得到 ¥1.39，结算展示约 10 kcal。扩展检查和截图见分析报告。

本地 `/api/*` 明确返回 503，让原应用使用已有离线分支。管理页面保留，但登录、账号、食材增删改、小报维护、门店后台保存需要原后端，本次未实现。玩家设置和预算使用原有 localStorage；选菜记录刷新后会清空，与恢复出的逻辑一致。

首次逆向时尚未部署；现已上线（见最新交付文档）。内置“小报”文字是目标网站内容，未核验其中新闻、营养或外链事实。
