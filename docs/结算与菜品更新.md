# 明细、结算与食材扩充

日期：2026-11-03。本次为用户确认方案后的本地功能优化；新增界面与食材不是从原站恢复的代码或数据。

## 实现

- 底栏突出已选种类、总重量、总金额与预算状态，提供“查看明细”和“上秤”。空盆可查看提示，不能上秤。
- 查看明细打开底部面板；食材逐行展示，支持加减，减到零移除，每种最多9份。面板独立滚动，合计和按钮固定在面板底部。清空需要二次点击确认。
- 上秤后先显示金额、重量、热量、预算和单价方式；食材账单按需展开。展示综合评分及最高/最低评价，全部20位评价默认折叠。
- 继续夹菜保留清单；重来一盆需确认，可以取消。支持关闭按钮、Escape、焦点返回、面板内Tab循环和背景滚动锁定。
- 新增50种常见食材，总数120种，覆盖所有7类，ID和名称无重复。新增重量、热量和密度为游戏估算，界面有说明，不作为实测营养数据。

## 文件

- `src/checkout-ui.js`：新明细面板、底栏和结算组件。
- `src/extra-ingredients.js`：50种新增模拟食材。
- `src/app.js`：原选菜状态、价格函数和评价引擎的接入；沿用原9份上限与按斤计价规则。
- `public/assets/checkout.css`：新增界面及响应式样式。
- `public/index.html`：加载新样式。
- `docs/ingredients.json`：更新后的120种食材数据导出。

## 实际验证

Chrome + Playwright视口：320×568、375×812、390×844、430×932、768×1024、1280×800、844×390，7组全部通过。每组执行空盆查看、搜索新增鲜虾、添加食材、增减份数、9份上限、称重、展开食材账单、展开20位评价、返回保留、重开确认/取消、清空确认与分类切换。检查页面横向溢出、底栏重叠、最后一项滚动至底栏上方、面板边界，以及页面JS异常，均通过。

计算断言：菠菜2份70g为¥2.77；菠菜9份315g为¥12.47；菠菜2份加鲜虾1份95g为¥3.76。另测菠菜、鲜虾、土豆粉、竹荪、羊肉卷组合：统一19.8元/斤总价¥6.14，启用荤素分价后总价¥6.84，结算单正确显示分价模式。

附加验证：预算超支提示、Escape退出、恢复背景滚动、关闭后焦点返回、Tab焦点循环、320px展开全部评价无横向溢出。模块语法检查通过。7组结构化结果见 `evidence/checkout-validation.json`。

浏览器视口模拟不等于iOS/Safari或Android真机验收。后台接口范围与此前一致，本次没有发布或部署。
