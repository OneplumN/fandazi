# 烧烤：食物与操作的动效

2026-11-04，已上线 https://malatang.oneplums.cn/#bbq 。当前版本 `20261104T024402Z`，上一版 `20261104T021257Z` 保留。

用户指出：仅有文字提示不够，食物本身应该灵动。本版以这一反馈替代“补齐文字状态即可”的判断。主要表现放在食物、受热和操作上，小号名字与熟度只作辅助。

## 实际变化

- 同一面受热时，食材连续变色，逐步出现烤痕与轻微收缩；过火后才逐渐增加黑斑。食用时保留做好的颜色和焦痕。
- 炭火明暗轻微变化，食材表面有油光、气泡和汁液滴落，热气缓慢上升，过火时烟更浓。
- 点击单串翻面时，夹子夹起这一串，抬高并旋转到另一面；其他串不跟着一起翻。重复操作可重新触发，回炉不会误播翻面。
- 撒料出现调味瓶摇动和颗粒落下，食材上的孜然/辣椒或蜜汁会保留。
- 上炉和放到保温盘有落下动作；保温后停止该串的受热动效。
- 暂停会冻结动效，离屏或切后台停止循环；关闭动效或系统减少动态效果时仍保留烹饪颜色和状态信息。默认静音不变。

所有效果使用现有SVG和CSS，无新增前端运行依赖。金币、会员、价格及轻松玩法沿用原规则。
