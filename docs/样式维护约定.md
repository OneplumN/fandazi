# 样式维护约定

HTML只引用public/styles/index.css，构建由Vite合并为一份哈希CSS。按tokens → base → components → pages → outings → motion读取和维护；不要再向HTML追加补丁文件。

- tokens.css：全局z-index与触区变量。浮层层级用变量；SVG内部0—6为局部层级。
- base.css：纸底、字体、基础货架及原生元素。
- components.css：通用控制、钱包/会员、结算弹层、碗与享用、推荐面板及各自媒体查询。
- pages.css：各店专属布局、制作场景和屏幕适配。
- outings.css：首页推荐、三位搭子、用餐小票和域名迁移的局部样式。
- motion.css：keyframes、过渡，以及暂停/离屏/隐藏/减少动态效果的覆盖。

区域是源码组织顺序，不使用原生@layer，以保留现有!important和specificity语义。不要因文件移动改变字体/间距；用保存的基线图和正式构建做对照。原CSS首次重构时已验证8组工作台像素一致。推荐等功能改动另走触摸、焦点和滚动锁检查。

分享封面可编辑源为docs/share-cover.html，当前输出public/share-cover-v2.png。新版本使用新文件名，并同步更新OG/Twitter元数据，避免第三方平台图片缓存。
