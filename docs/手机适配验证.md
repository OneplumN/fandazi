# 手机端适配修复与验证

修改日期：2026-11-03。仅新增 `public/assets/mobile.css` 并在本地 HTML 引用，原站发布物保留不变。

修复：
- 手机货架头部改为单列可收缩网格，分类按钮在容器内换行，搜索框不再撑宽分类区。
- 手机底栏改为盆/金额一行、操作按钮一行，金额保留足够宽度；列表模式独占一行，清单水平滚动。
- 页面底部留出底栏空间，底栏考虑安全区域。
- 窄屏禁用推荐抽屉的透明悬停感应区，避免截获上秤点击；保留搭配按钮。
- 收窄称重评价标题的最小宽度，兼容 320px 屏幕。

验证使用本机 Chrome 的 Playwright 浏览器自动化，视口高度 844px。宽度 320、375、390、430、768、1280px；每种宽度检查空盆、已选菜、清单三种状态，共18组布局检查，0失败。检查页面横向溢出、分类栏边界、金额区宽度、底栏三部分的矩形重叠。

每种宽度实际执行：添加菠菜和生菜 → 切换清单 → 移除菠菜 → 上秤 → 返回修改 → 切回盆视图 → 点击蛋与杂项 → 确认鸡蛋可见。全部通过。修复前320–430px视口的页面宽度均被撑到454px，390px金额区宽度只有27px；修复后页面宽度与视口一致，390px金额区宽度232px。手机列表模式底栏高度188px，页面预留300px滚动空间。

这属于浏览器视口模拟验证，未声称在真实 iPhone/Android 或 Safari 上完成真机测试。截图见 `mobile-fixed.png`。结构化前后结果保存在 `evidence/mobile-layout-before.json` 和 `evidence/mobile-layout-after.json`。
