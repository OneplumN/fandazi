# 新增食材图标画风修正

2026-11-03。用户指出新增图标和原有画风不统一，确认问题为图标造型，而非菜品选择。

之前新增50种食材只有通用shape配置，未在原专属图标映射中注册，因此鲜虾、粉面、内脏等食材共用通用长条/圆形。现在增加 `src/extra-food-icons.js`，为50个新增ID逐项绘制造型，并在原 `Ca` 渲染器的专属映射中注册。
