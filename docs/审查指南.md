# 饭搭子代码审查指南

本次推送对应已上线的20261104T084355Z版本，主站 https://fandazi.oneplums.cn/ 。审查对象是前端、游戏模型、本地存储、手机交互与静态构建；原管理后端未恢复。

## 复现起点

Node.js22.12+，执行 `npm ci`、`npm test`、`npm run build:static -- --out-parent ./work`。规则测试应为44项通过。开发服务用 `npm start`，正式产物用 README 中的 Vite preview 命令；二者都应检查。路由为 `#home`、`#malatang`、`#bbq`、`#tea`、`#hotpot`、`#breakfast`、`#shop`、`#receipt`。

## 产品约束

五店消费者视角，不做闯关、强制订单、每日任务和通关奖励。每天100金币，不付真实款；消费增长会员，取消未完成用餐退款并撤回相应成长。画风使用原SVG/角色素材，手机直接点食物操作，避免增加确认与复杂文字。

## 优先检查

1. 价格和资金：推荐金额是否等于实际消费，赠币是否同日去重，快速点击/多标签页是否重复扣费，未完成离开/重载退款是否正确。
2. 享用与存储：食物点击当下记录一口，动画约680ms后更新画面；重复输入阻断、最后一口后小票、动画中离开/刷新、存储不可用、其他标签页同步是否一致。享用不再收费。
3. 推荐与小票：三位搭子、不同预算/余额/口味带入有效菜单；火锅推荐需点击标价按钮才下锅；每家店小票显示实际金额、可下载PNG，真正刷新文档后最近小票仍可读。
4. 手机：320/375/390/430宽、短屏和横屏；分类横滑、底部安全区、推荐抽屉/结算滚动锁、焦点恢复、44px目标与拖动不误点；减少动态效果和关闭动效时可直接吃。
5. 域名迁移：origin/source/nonce匹配、旧数据保留、新站有消费时拒绝覆盖、迁移后重新加载偏好。两个真实域名才能完整验证跨域，localhost无法替代。
6. 构建与部署：2个哈希JS/1CSS、静态资源路径、无玩家bootstrap请求、HTML校验更新、哈希资源长缓存且历史哈希保留；不要把主动503的管理API当成玩家加载依赖。

## 现有验证范围

44项Node规则测试；本地8尺寸40组五店付费用餐；本地及线上390/1280五店动作、减少动态效果/动效关闭12项；五店推荐带入、实际扣费、PNG下载、真实页面刷新回看；原生CDP触摸拖动/连续点击、慢钱包写入；跨域迁移、防覆盖与HTTPS检查。浏览器脚本和录屏原本在开发机交付目录，本仓库内可直接复跑的是Node规则测试与构建。未做实体手机/微信客户端、云端账号同步或管理后台验收。
