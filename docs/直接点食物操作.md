# 直接点食物操作（2026-11-04）

已发布 https://malatang.oneplums.cn/ ，版本20261104T031238Z；上一版20261104T025035Z保留可回退。

奶茶：点杯子按标价开做，制作中点杯摇匀，完成后直接点杯喝。甜度/冰量/杯型折叠。
火锅：点架上食材按份下锅，无开锅确认；点锅内食材捞起，捞早的直接点碗内食材免费回锅。捞完且无未熟食材后，点碗内食物即吃，第一口结束制作并保留用餐进度。
早餐：点饼10金币开摊，点饼翻面，点鸡蛋加入；点配菜或酱料自动出锅加料，再点饼包好。也可直接包起不加配菜的饼。
麻辣烫：选好后点标价“开吃”直接扣币上桌，免费账单仍在明细中。付费后先看食物，账单与点评折叠。

沿用原SVG、配色和动作；每日100金币、消费会员、取消未完成餐食退款不变。同步锁与账本幂等防止快速连点重复收费，付款时冻结相关操作。

验证：34项规则测试；320/375/390/430/768/1280/844七种宽度共28组四店直接制作/吃喝流程；390/1280线上8组四店流程和2组烧烤翻面回归。奶茶/早餐快速20连点、麻辣烫快速20连点只扣一次；免费账单不收费；火锅免费回锅和第一口进度保留通过。各店取消退款、余额不足、键盘Enter、暂停恢复及减少动效通过；原每日赠币、迁移、并发购买、刷新退款、受限存储回归通过。人工查看手机截图与技能客户端制作截图。手机验证使用Chrome视口，并非物理手机。
