# 奶茶、火锅、煎饼动效精修

2026-11-04 已发布 https://malatang.oneplums.cn/ 。当前版本20261104T032309Z；上一版20261104T031238Z保留。

奶茶：独立杯身摇动，手动点击增加一段摇杯动作；液面、奶层、冰块、珍珠与吸管分层错拍。摇匀时保留实际配方和渐变融合色，大小杯不再被动画覆盖尺寸变换。
火锅：九处不同步鼓泡与破泡涟漪，三道汤面水流和轻热气；食材落入后轻浮。未开锅保持静止，点击仍直接下锅/捞起。
煎饼：锅保持稳定，铲子抬起饼，饼变薄翻转并落回锅面；小油泡和连续烙色作辅助。快速重复点击能重新触发动作，不加等待步骤。

保持原深棕描边、奶油底色和食物表情，没有增加说明文案、运行库或新操作步骤。原付费、每日100金币、会员与退款方案保持。

暂停会冻结画面；离屏、浏览器隐藏停止循环；关闭动效或系统减少动态效果时取消空间动画，继续保留食材熟化颜色、状态与点击操作。
