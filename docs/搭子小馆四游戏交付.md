# 搭子小馆：四个新游戏交付

2026-11-03，已部署到 https://malatang.oneplums.cn/ 。首页为五家小店入口，原有麻辣搭子及120种食材保留。

## 画风与手机操作

沿用原有奶油底色、深棕轮廓、食材专属SVG、表情函数和角色头像；另绘烤炉、奶茶杯、小料、火锅和煎锅插图。未新增运行时依赖、远端图片、付费服务或数据库。

手机/平板采用上下布局、44px以上的主要触控按钮、底部快捷操作栏和安全区域边距。选完食材可直接开烤、摇匀或回锅边；暂停后快捷栏可以继续游戏。计时局支持暂停、切出页面自动暂停、回来后手动继续；中途从游戏页返回首页会先确认，包含焦点约束及Escape取消。最高分仅存在当前设备，localStorage不可用时仍可游玩。

## 代码与启动

- `src/games/rules.js`：纯规则、计时状态机、订单和评分。
- `src/games/bbq.js`、`milk-tea.js`、`hotpot.js`、`breakfast.js`：四个独立交互视图。
- `src/games/common.js`：时钟、结果、暂停、导航确认和手机快捷栏。
- `src/games/art.js`：与现有食材风格一致的器具插画。
- `src/games/hub.js`：五游戏入口、标题、hash路由和最佳成绩。
- `public/assets/games.css`：响应式布局和插画动效；尊重减少动态效果设置。
- `tests/games.test.mjs`：规则回归测试。

本地运行：`npm start`；规则验证：`npm test`；静态构建：`npm run build:static`。hash路由支持直接打开和刷新，无需增加Nginx重写规则。原站后台仍未恢复，本次不涉及后台接口。

`window.render_game_to_text()`提供当前游戏状态；`window.advanceTime(ms)`可进入人工时钟模式用于确定性浏览器测试，重载或切换游戏后恢复正常时钟。普通游玩不调用该测试接口。

## 验证结果

1. 13项Node规则测试通过：双面烤制、夹生/烤焦、暂停、容量、所有奶茶订单可达100分、配方锁定、火锅捞取/空锅/每局12份、早餐三单与超时、无效ID/时长、食材图标引用。
2. 7组视口（320×568、375×812、390×844、430×932、768×1024、1280×800、844×390）×5个游戏，共35组完整操作与结果回归通过；页面无横向溢出、面板越界，手机底栏在屏内。
3. 4个新游戏均运行develop-web-game技能原版客户端（仅为使用已有Playwright依赖复制到工作目录，无修改客户端内容），执行输入/计时并检查状态、截图；未产生console error记录。由于本项目为DOM/SVG交互，复杂多步操作另外用Playwright语义定位验证。
4. 浏览器边界通过：6串不重叠、烤焦外观、退出确认时暂停、Tab循环/Escape、最佳分刷新保留、真实时钟运行、切后台暂停、手动恢复、空锅结束、早餐超时账本、非法hash回首页、禁用localStorage仍可结算。
5. 线上HTTPS按390px和1280px各跑5个游戏，共10组真实服务器流程通过；40个发布文件SHA-256校验通过。浏览器配置了域名到服务器的显式解析映射，以绕过执行环境偶发本地DNS超时，没有关闭TLS证书校验。

手机为浏览器视口模拟验证，未声称完成iOS/Safari或Android真机兼容性验收。游戏里的火候、配方、价格均为玩法设定。
