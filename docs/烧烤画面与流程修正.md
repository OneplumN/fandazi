# 烧烤画面与流程修正

2026-11-04，已上线 https://malatang.oneplums.cn/#bbq 。当前版本 `20261104T004029Z`，上一版本 `20261103T141421Z` 保留。

用户截图指出烧烤不合理。查明原有选串和烤制共用卡片容器，选满六串时商品卡遮挡烤炉；食材又直接复用麻辣烫的肉卷、鸡胸图标，未表现真正的串型。这次以用户截图为修正依据，取代此前“用餐精修已足够”的判断。

## 修改

- 选串阶段只显示独立待烤盘，点击串可拿掉；确认下单后才上炉。
- 12种烧烤有独立三段串型：肉块、鸡肉块、去头虾仁、肠、鱿鱼圈、香菇、豆干、玉米、西兰花、茄子、藕片，沿用深棕线条、暖色与表情。
- 上炉后直接把六根串排在烤网上，露出炭火和炉体；食材不再装在白色卡片里。每根有编号，可以直接点串翻面。
- 正反面火候、翻面、保温操作放到炉子下方；保温盘可以直接回炉。手机上保持可点击尺寸，并压缩中等手机屏幕的操作行。
- 货架、待烤、炉上、保温与享用使用同一套串型；烤熟、烤焦、撒料与蜜汁的外观对应制作状态，吃串仍逐口减少。
- 选串时先展示食材架，调味放后面；预选口味后开烤再撒，准备阶段不显示不可用的大撒料按钮。

每日100金币、消费会员、确认下单扣币及取消退款沿用原规则，没有改变价格。

## 验证

28项原规则/钱包/用餐测试通过。320、390、768、1280像素下，按用户截图选择6串（含2串鸡肉），验证准备区与烤炉分开、六串满炉、无卡片覆盖、点击范围、双面翻转、暂停、保温/回炉、撒料、出炉和吃串不再扣币；无横向溢出或页面错误。

线上390和1280像素的同样流程通过；五家店共10组线上付费与吃喝流程回归通过。实际查看了桌面/手机截图、待烤盘、烤网预览与开发技能客户端截图。设计机械检测无问题。50个发布文件SHA-256验证后原子切换，HTTPS与既有regex站点为200。没有物理手机测试。

实现：`src/games/bbq.js`、`bbq-art.js`、`dining.js`、`dining-model.js`、`public/assets/bbq-layout.css`。原有70种麻辣烫食材图标未更换。
