# 搭子小馆：用餐互动精修

已上线 https://malatang.oneplums.cn/ 。版本 `20261103T141421Z`，上一版本 `20261103T112758Z` 保留可回退。

## 这次更新

- 烧烤：出炉后每串一共三口，每点一次串上的食物减少一份；保留翻面、撒料、保温及逐串火候点评。
- 奶茶：可在自动摇匀时点“再摇一下”，不用必须手动操作；成品可喝五口，液面逐口下降，最后留下空杯。
- 火锅：捞起的食材会出现在带表情的小碗里；结算后按份点击享用，吃完留下空碗。
- 早餐：增加翻饼反馈，包好的饼放在餐盘上，四口逐渐咬出缺口，最后留下空盘。
- 麻辣烫：免费称重和点评继续保留，确认开吃后出现餐桌，按照食材数量逐口享用。重新打开同一账单保留吃到哪一口，不重复收费。
- 制作时增加翻面、加蛋、加料、摇匀、捞菜的即时反馈，继续沿用原有食材SVG、表情、角色和奶油色/深棕描边。
- 新增“声音与动效”设置：默认静音，可开轻声音效、支持设备的触感反馈，也可关互动动效；尊重系统减少动态效果设置。切后台暂停制作并停止声音。

每日100金币、下单扣币、消费会员、未完成订单取消退款规则沿用上一版；吃喝动画不再扣币，也不发放闯关奖励。不要求吃完才能离开或再做一份。

## 数据与实现

用餐进度独立于金币账本；同一账单重开会恢复进度，最多保留80份用餐进度。四个制作页面仍沿用原有页面会话进度，刷新后可通过原未完成订单入口退款；此版没有新增跨设备存档或历史餐桌入口。

`src/games/dining-model.js` 定义份数与吃喝推进；`dining.js` 连接餐桌、进度和原有美术；`experience.js` 管声音、触感及动效偏好。`art.js` 增加液面与咬痕，`common.js` 和五店页面接入，样式位于 `public/assets/dining.css`。
